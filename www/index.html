🛰️ SAM Pocket Demo · ArcGIS Maps SDK for JavaScript
Mapas inteligentes en tu bolsillo

Este demo corre sobre el ArcGIS Maps SDK for JavaScript y se empaqueta como app Android. Todo lo que ves son ejemplos reales del SDK con datos públicos.

  • 🧩 Un solo código: lo que se hace para la web se reutiliza en el teléfono.
  • 📡 Sensores del dispositivo: GPS, precisión y seguimiento en tiempo real.
  • ⚡ Análisis en el equipo: medir, calcular radios y áreas sin depender de un servidor.
  • 🔌 Conecta lo que ya existe: GeoJSON, servicios ArcGIS y APIs propias o abiertas.
  • 🎨 Visualización a la medida: símbolos, mapas de calor, etiquetas y ventanas emergentes.
  • 🚀 Actualizaciones ágiles: cada cambio en el código genera un APK nuevo en minutos.

Demo de concepto. Sismos: USGS · Clima: Open-Meteo · Lugares con ubicación referencial.
